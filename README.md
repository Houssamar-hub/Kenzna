# كنزنا | Kenzna - منصة التجارة الإلكترونية للمنتجات الطبيعية والمكسرات الفاخرة 🌿👑

> **"كنز من الطبيعة إلى بابك"**
> منصة تجارة إلكترونية مغربية وعربية متكاملة واحترافية متخصصة في بيع الفواكه الجافة، المكسرات المنكهة والمحمصة، البذور، المنتجات المعسلة، والخلطات الملكية.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

### 🖥️ Frontend (الواجهة الأمامية)
- **React.js 18 + Vite 6**: سرعة فائقة في البناء والتطوير.
- **Tailwind CSS**: تصميم عصري ومريح مع لوحة ألوان مستوحاة من التراث المغربي والطبيعة.
- **RTL Support**: دعم كامل 100% للغة العربية مع خطوط Google الخطوطية (Cairo & Tajawal).
- **React Router DOM v7**: توجيه وحماية المسارات (Protected Routes).
- **Context API**: إدارة الحالة العامة (AuthContext, CartContext, FavoritesContext).
- **Lucide React**: أيقونات عصرية عالية الدقة.
- **HTML2Canvas & jsPDF**: توليد فواتير الشراء وتقارير المبيعات بصيغة PDF فورياً.
- **React Hot Toast**: تنبيهات تفاعلية فورية باللغة العربية.

### ⚙️ Backend (الخادم وقاعدة البيانات)
- **Node.js & Express.js (ES Modules)**: معمارية RESTful API نظيفة وقابلة للتوسع.
- **MongoDB & Mongoose**: تخزين البيانات مع schemas دقيقة وعلاقات متناسقة ودعم الـ In-Memory Fallback.
- **Cloudinary SDK & Multer**: معالجة ورفع صور المنتجات مباشرة إلى السحابة مع روابط HTTPS دائمة ومحسّنة.
- **JWT & bcryptjs**: نظام أمان وتوثيق مشفر مع حماية الصلاحيات (Role-Based Authorization).

## 🚀 تشغيل المشروع محلياً (Local Development)

### 1. إعداد الخادم (Backend)
```bash
cd server
npm install
npm start
```
*الخادم سيعمل على المنفذ: `http://localhost:5001`*

### 2. إعداد الواجهة الأمامية (Frontend)
```bash
cd client
npm install
npm run dev
```
*واجهة المتجر ستعمل على: `http://localhost:5173`*

## 🌟 الميزات الحصرية والمتقدمة

1. **📄 نظام توليد الفواتير التلقائي (Instant PDF Invoices)**:
   - نافذة منبثقة تلقائية فور إتمام الطلب تتيح تنزيل فاتورة PDF ملكية برقم الطلب وتفاصيل الزبون.
   - إمكانية تنزيل الفاتورة من صفحة حساب الزبون ومن لوحة تحكم الإدارة.
2. **📊 تقارير المبيعات والأداء للإدارة (Executive Sales PDF Report)**:
   - تقرير تحليلي يوضح إجمالي الإيرادات، عدد الطلبات، والمبيعات بالدرهم المغربي (MAD).
3. **☁️ رفع الصور السحابي عبر Cloudinary**:
   - إمكانية رفع صور المنتجات مباشرة من الجهاز مع معاينة فورية وروابط محسّنة تلقائياً.
4. **⚖️ تحديد الأوزان والأسعار**:
   - دعم بيع المنتجات بعدة أوزان (250g, 500g, 1kg) مع حساب فوري للمخزون والسعر.
5. **🎟️ نظام الكوبونات والخصومات**:
   - خصومات بنسبة مئوية أو مبالغ ثابتة مع فحص الحد الأدنى وتاريخ الصلاحية.
6. **🇲🇦 تجربة مغربية 100%**:
   - نظام الدفع عند الاستلام (Cash on Delivery)، والشحن المجاني التلقائي للطلبات التي تفوق 300 د.م.

## 🌐 دليل النشر والاستضافة (Deployment Guide)

### نشر الواجهة الأمامية (Vercel / Netlify):
1. قم بربط مستودع GitHub بـ Vercel.
2. حدد المجلد الرئيسي: `client`.
3. أمر البناء: `npm run build`.
4. مجلد الإخراج: `dist`.

### نشر الخادم (Render / Railway / VPS):
1. حدد المجلد الرئيسي: `server`.
2. أمر البدء: `node server.js`.
3. قم بإضافة المتغيرات البيئية من ملف `server/.env.example`.
